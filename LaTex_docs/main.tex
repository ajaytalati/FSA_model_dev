\begin{abstract}
\noindent
This document provides a comprehensive graduate-level introduction to the FSA-v2 (Fitness-Fatigue-Amplitude) physiological model. We detail the biological foundations based on the Banister impulse-response framework, the mathematical formulation using Stochastic Differential Equations (SDEs) in a reparametrized form, and the numerical implementation within a JAX-based sandbox environment. These notes are designed for students and researchers aiming to develop, tune, and validate the FSA model independently of a larger inference pipeline.
\end{abstract}
