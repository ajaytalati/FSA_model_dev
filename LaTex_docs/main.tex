\begin{abstract}
\noindent
This document provides a comprehensive graduate-level introduction to the FSA-v4 (Fitness-Strength-Fatigue-Amplitude) physiological model. We detail the biological foundations based on the Banister impulse-response framework, its extension to bimodal training (aerobic and resistance), the mathematical formulation using Stochastic Differential Equations (SDEs) in a reparametrized form, the variable-dose sensitivity dynamics of Busso (2003), and the numerical implementation within a JAX-based sandbox environment.
\end{abstract}
